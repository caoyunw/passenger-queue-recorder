# 乘客队列记录工具设计

## 目标

制作一个本地单文件网页工具，用于拆解竞品关卡时记录不同颜色乘客的出现顺序。乘客队列按以下顺序分为三个部分：

1. 传送带
2. 左侧队列
3. 右侧队列

工具需要为每个部分分别生成一份可复制配置，并额外生成一份整体配置。车辆布局截图不在本工具识别范围内，但工具需要支持记录每次操作选择的车辆和四个固定车位的剩余座位状态。

## 交付形式

工具为一个独立的 `index.html` 文件，CSS 和 JavaScript 均内嵌在文件中。使用时直接在浏览器中打开，无需安装、启动服务或下载外部依赖。

## 颜色映射

初始映射如下：

| 颜色 | 映射值 |
| --- | --- |
| 红色 | `1` |
| 黄色 | `2` |
| 蓝色 | `3` |
| 绿色 | `4` |
| 粉色 | `5` |
| 紫色 | `6` |
| 天蓝色 | `7` |
| 棕色 | `8` |
| 橙色 | `9` |
| 黑色 | `10` |
| 白色 | `11` |

用户可以新增颜色：填写显示名称，并通过取色器选择按钮颜色。新颜色的映射值自动设为当前最大映射值加一。已有映射会在不同关卡之间保留，并在关闭或刷新浏览器后继续保留。

默认映射发生变更时需要升级本地存储版本。旧队列不能直接沿用，以免相同数字被解释为不同颜色。

## 录入流程

页面采用固定左侧导航，共有五个阶段：

1. 传送带
2. 左侧队列
3. 右侧队列
4. 全部配置
5. 车位记录

正常操作时通过“下一步”按钮依次前进。用户也可以随时点击左侧导航，返回之前的阶段或打开后续阶段进行修改。

每个录入阶段展示：

- 当前区域名称和乘客数量
- 每种颜色对应的录入按钮
- 新增颜色按钮
- 已录入的乘客序列
- 撤销按钮
- 下一步按钮

点击颜色按钮时，将对应映射值追加到当前区域。点击已录入的序列项时，删除该项。页面需要通过悬停样式和提示文案明确说明序列项可以点击删除。

## 键盘快捷键

当输入框、文本框或弹窗字段没有获得焦点时：

- 按数字键，追加具有相同映射值的颜色。
- 按 `Ctrl+Z`，撤销最近一次序列编辑。

快捷键仅在三个录入阶段生效。在“全部配置”和“车位记录”阶段按数字键不会追加乘客。

撤销功能将当前区域恢复到上一次修改前的序列状态，覆盖新增乘客和删除乘客两种操作。当前关卡内，每个区域各自维护独立的撤销历史。

## 生成配置

“全部配置”阶段展示四张输出卡片：

| 输出项 | 内容 |
| --- | --- |
| 传送带配置 | 传送带的映射值 |
| 左侧队列配置 | 左侧队列的映射值 |
| 右侧队列配置 | 右侧队列的映射值 |
| 整体配置 | 按传送带、左侧队列、右侧队列的顺序拼接 |

每份配置使用不带括号的英文逗号分隔格式，例如：

```text
1,2,3,1
```

每张输出卡片都有独立复制按钮，便于将单份配置粘贴到指定的飞书表格单元格中。

## 车位操作记录

“车位记录”阶段用于记录玩家每次从停车场选择的车辆，以及结算后四个固定车位的状态。工具不模拟传送带环形移动，不复用乘客队列配置。

核心规则：

- 车位固定为 `1` 到 `4` 号，靠左车位优先级更高。
- 新车进入当前最靠左的空车位。
- 车辆由颜色和座位数表示，座位数为 `4`、`6` 或 `10`。
- 车辆颜色不使用下拉框。每个颜色显示为车辆选择卡片，卡片内直接提供 `4座`、`6座`、`10座` 按钮。
- 已占用车位需要直接显示车辆颜色，便于从游戏画面快速核对。
- 记录剩余座位，而不是已上乘客数。
- 车满开走时，用户点击对应车位的“已开走”，该车位变为空。
- 工具记录每辆车进入车位时对应的批次编号。车辆开走时，日志自动写入进入批次、开走批次和总占位批次数。
- 用户可以连续点击多辆车进入车位，工具将这些车辆暂存在当前批次内。
- 点击“记录本批次”后，工具保存一条包含本批次选择车辆、进入车位顺序和当前四个车位快照的日志，并清空当前批次暂存。
- 用户可以将当前日志保存为一个单局车辆记录。保存时提供“第几关”和“第几局”两个输入框，生成名称如 `第3关第2局`。已保存单局可以继续查看、载入当前日志、复制或删除。

日志导出使用制表符分隔，便于粘贴到飞书表格：

```text
批次	本批次选择车辆	进入车位顺序	1号车位	2号车位	3号车位	4号车位	开走车辆	占位时长	备注
5	红色4,蓝色6	红色4->1,蓝色6->2	空	蓝色6剩1	空	空	红色4	红色4：1→5，共5步	红车开走
```

## 本地持久化

使用浏览器的 `localStorage` 在本机保存状态，包括：

- 颜色映射
- 三个区域已经录入的序列
- 车位状态和操作日志
- 已保存的单局车辆记录
- 当前所在阶段

每次相关状态变化后立即保存。重新打开或刷新页面时，恢复最近保存的状态。

## 重置操作

“全部配置”阶段提供：

- `开始记录下一关`：清空三个区域的录入内容和撤销历史，保留全部颜色映射，并返回传送带阶段。
- `彻底重置`：清空录入内容和自定义颜色映射，恢复全部初始映射，并返回传送带阶段。执行前必须弹出二次确认。

## 异常处理

- 复制成功后，在对应复制按钮上显示短暂反馈。
- 如果浏览器不支持剪贴板 API，则使用临时文本元素完成兼容性复制。
- 新增颜色时，名称去除首尾空格后不能为空。
- 允许某个区域为空。空区域显示为空字符串，并且仍然可以执行复制。

## 视觉方向

采用适合反复点击的紧凑桌面工作台布局：

- 左侧固定阶段导航
- 主录入区使用较大的颜色按钮
- 已录入序列以易于检查和删除的圆形色块展示
- 清晰展示乘客数量和自动保存状态
- 窄窗口下，左侧导航自动移动到内容区上方

## 验证清单

浏览器手动验证必须覆盖：

1. 通过鼠标点击和数字快捷键追加乘客。
2. 点击序列项删除乘客。
3. 分别撤销新增操作和删除操作。
4. 在各个阶段之间切换，并修改之前录入的内容。
5. 新增自定义名称和颜色，并验证自动分配映射值。
6. 刷新页面，验证颜色映射、队列和当前阶段均已恢复。
7. 分别复制四份配置，并验证整体配置的拼接顺序。
8. 开始记录下一关，验证颜色映射保留且队列清空。
9. 彻底重置，验证二次确认和初始映射恢复。
10. 车位记录中通过颜色卡片连续选择多辆车辆、点击“记录本批次”、修正剩余座位、点击已开走，并复制详细日志。
11. 保存单局车辆记录，验证名称来自“第几关 / 第几局”，并验证清空当前车位后仍能从已保存单局载入或复制。
